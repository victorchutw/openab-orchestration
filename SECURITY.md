# Security policy

Report suspected vulnerabilities privately by emailing
`victorchu@gamasys.com.tw` with the subject `OpenAB Orchestration security`.
Do not open a public issue, pull request, discussion, or chat thread for a
suspected vulnerability.

Include the affected version, a minimal reproduction, expected impact, and a
safe way to contact you. Do not attach live credentials, Secret Material,
private Installation Configuration, runtime databases, target source, agent
sessions, transcripts, logs, or real Evidence Bundles. Describe sensitive
artifacts first so the maintainer can arrange an appropriate private transfer
if they are necessary.

The maintainer will acknowledge the report, coordinate investigation and any
disclosure timing, and identify a public release or advisory when a remediation
is ready. This project currently supports only the latest release on the
documented reference profile and makes no SLA commitment.
